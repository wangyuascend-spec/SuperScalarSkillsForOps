测了哪些输入

种子 42。balanced 对全部 E 个专家无放回抽 K 个；skewed 从前 max(K, E/4) 个专家无放回抽 K 个，小网络抽自前 4 个，大网络抽自前 28 个；extreme 的所有 token 固定选择专家 0 到 K−1。输入分布与 Greedy 运行时选择的 mode 是两个概念。

改动及验证边界

基线为主仓 PR !1118 的 f92d13f，采用默认设置。候选在所有分布式 trusted 规格提前统计本卡 topk。多个 AIV 时，AIV 0 负责 Exchange 和 Greedy，其余 AIV 将每个 chunk 的共享 UB 直方图写回 counts。只有一个 AIV 时由 AIV 0 顺序完成。Mode 1 在第一次阶段同步后可以直接读取 counts；mode 0 和 2 也付出 Count 的成本。旧版小网络默认已经提前 Count，大网络的调度有实质变化。

DSL 参考选择原源码已有的标量 Count 分支。各实现使用同一 local tpe 和 topk，并核对独立 CPU golden。另测分布式单 AIV trusted、四 AIV strict 及单卡四 AIV trusted 的尾块、连续调用和入口保护。本表给出四卡延迟，未测试八卡。
