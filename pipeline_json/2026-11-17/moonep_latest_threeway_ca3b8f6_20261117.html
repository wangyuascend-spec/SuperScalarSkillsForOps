对照边界

DSL 关闭 SIMD Count，沿用原有 scalar 分支，以规避该安装环境已实证的计数异常与大专家数编译栈限制。DSL 的最大规划核数设为32并在 workspace 创建前生效，实际 profiler 核数已核对。这改变调度配置；结果不代表 DSL 自然56核配置的上限。

DSL 使用 URMA／UBC_CTP；PyPTO 使用远端 GM 映射与 UB tile／MTE put/get 的 UB_MEM 路径。底层机制不同，通信 gap 不能全部归为 kernel 编排。通信包含各自准备、信号和到达等待。三个隔离 kernel 的时间不可简单相加还原融合时间。原推荐八卡 E224 未在本次四卡环境实测。
